\section*{Data Availability}
The option data used in this study are publicly available from the DoltHub repository \href{https://www.dolthub.com/repositories/post-no-preference/options}{post-no-preference/options}, which provides historical option records for SPY and XOP. The analyses in this paper use only these publicly accessible records, and no proprietary datasets were used. The data were accessed on Oct 15, 2025.
