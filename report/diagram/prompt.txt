Three parallel vertical columns below, labeled:
  Left:   "Policy  π_θ"   [blue border]
  Middle: "Value Baseline  V_φ"  [gray border]
  Right:  "Price Estimator  P_ψ"  [orange/accent border, slightly wider]

Each column has:

  [ResNet block × D]  
  Drawn as stacked rounded rectangles:
    Linear → LayerNorm → ReLU → Linear  +  skip-connection arrow on the side

OUTPUT HEADS:

  Policy π_θ:
    → Two branches: μ_π   and  σ_π 
    → Output: "Hedge ratio  a_t ~ N(μ_π, σ_π²)"
    Right callout: "✓ Bounded exploration noise
                    prevents degenerate policies"

  Value Baseline V_φ:
    → Single linear head
    → Output: "Cost-to-go  V(x)"
    Right callout: "✓ Per-step signal only
                    — reduces gradient variance"

  Price Estimator P_ψ:
    → Linear head → scalar  σ̂  (latent volatility, positive)
    ↓
    [Shaded highlight box] "Closed-form Pricing Layer  P(S, K, τ, r, σ̂)"
        — rectangular-double-border to emphasise it is a fixed formula, not learned weights
    ↓
    Output: "Replication price  V̂"
    Right callout (two stacked badges):
        "✓ End-to-end gradient flow,
         Interpretable output"

SHARED WEIGHTS annotation:
  Curly brace connecting P_ψ backbone to π_θ backbone on their shared side,
  labeled: "shared ResNet weights"
